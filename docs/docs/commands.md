# コマンド一覧
コマンドの一覧です。<br>
これらのすべてを覚えなくても使用することはできます。

## /purge
自分のメッセージだけを指定分削除します。
#### デフォルトの実行権限
チャンネルの管理

## メッセージを削除
選択した自分のメッセージを削除できます。
#### デフォルトの実行権限
メッセージの管理

## ここから下を削除
選択した自分のメッセージより新しいメッセージを100件まで削除します。
#### デフォルトの実行権限
チャンネルの管理

## /help
コマンドの使い方を表示します。
#### デフォルトの実行権限
チャンネルの管理
