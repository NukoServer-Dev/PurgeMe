# コマンドの権限
PurgeMeはコマンドの権限を<br>
Discord公式の連携サービスから設定できます。

## 必要な権限
この設定には、「サーバーの管理」権限が必要です。

## 権限の設定方法
1. サーバーの設定を開いてください
![設定を開く](<../images/open-setting.png>)
2. 「連携サービス」を選択してください。
3. 「PurgeMe」を選択してください。
4. 「コマンド」から必要なコマンドの上書き権限を設定してください。
![alt text](<../images/commands.png>)
5. サーバーの権限を持たないメンバーがそのコマンドを実行できるかを確認してください。
